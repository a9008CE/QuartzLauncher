05 FAQ

常见问题，快速解答

星落 LaunCher 支持哪些 Minecraft 版本？
支持从 1.0 到最新版本的几乎所有 Minecraft 版本，包括 Forge、Fabric、Quilt、NeoForge 等主流加载器
启动器需要什么 Java 版本？
启动器本身需要 Java 17 或更高版本运行Minecraft 的 Java 需求由启动器自动管理，不同版本的游戏会匹配对应的 Java
如何离线游玩？
在启动器设置中选择「离线模式」，输入游戏用户名即可离线模式支持自定义皮肤库和 Steve / Alex 模型切换
Mod 自动依赖解析是怎么工作的？
安装 Mod 时，启动器会自动扫描其依赖列表，从 CurseForge 或 Modrinth 下载缺失的前置 Mod，无需手动逐个查找安装
启动器会自动更新吗？
是的每次启动时自动检查新版本，发现更新后后台静默下载，用户点击确认即可完成替换升级，不丢失任何数据
更新后启动器消失了怎么办？
更新过程会将日志写入 Launcher/update-apply.log如果更新异常，检查该文件排查原因启动器会保留旧版本备份，重新运行即可恢复
支持 macOS 或 Linux 吗？
目前仅支持 Windows x64 平台macOS 和 Linux 支持计划中，后续版本会陆续推出
